# Kidverse Web Application

> Next.js-based web interface for Kidverse

## Overview

Modern, responsive web application for both kids and parents:

- **Kid Interface**: Fun, engaging, and safe browsing experience
- **Parent Dashboard**: Comprehensive monitoring and control panel
- **Real-time Updates**: WebSocket-based live activity monitoring
- **Responsive Design**: Mobile-first, works on all devices

## Features

- Server-side rendering with Next.js
- TypeScript for type safety
- Tailwind CSS for styling
- shadcn/ui component library
- Real-time notifications
- Progressive Web App (PWA) support

## Getting Started

```bash
cd web
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)
